# 股票风格分类方法

先分类，再评估。分类依据**全部来自脚本输出的真实数据**（行业 + 财务特征），
不依赖主观印象。

## v1.0 范围

当前版本**只实现成长股评估框架**。判定为其他类型的股票，明确告知用户
"当前版本仅实现成长股框架"，并给出分类依据，不强行打分。

## 成长股判定标准（满足其一即归为成长类候选，再排除以下列出的类型）

依据 `derived_metrics.json` 与 `basic.json`：

1. 近 3 年营收增速均值（`rev_yoy_avg3`）≥ 15%，或
2. 近 3 年净利增速均值（`profit_yoy_avg3`）≥ 20%，且
3. 增速由主业驱动：近 3 年扣非增速均值（`deducted_yoy_avg3`）不为负，
   避免一次性收益（卖资产、政府补助）推高利润的假成长。

### 排除项（即使增速高也不算成长股，不适用本框架）

| 情况 | 依据 | 处理 |
|------|------|------|
| 强周期行业（煤炭、钢铁、有色、化工、航运、建材等） | `basic.industry` | 增速是周期性的，按周期框架（未实现，提示不适用） |
| 金融股（银行、保险、券商、多元金融） | `basic.industry` | 有专门估值体系（未实现，提示不适用） |
| 亏损或微利（净利 ≤ 0 或 PE-TTM ≤ 0） | `derived.profit_yoy_avg3` / `pe_ttm` | 常规估值失效，提示不适用 |
| 上市不足 3 年 | `basic.list_date` | 无足够历史数据，可提示数据不足（分位数亦不可得） |

## 未来扩展（预留，不在 v1.0 实现）

- **红利价值股**：股息率 `dv_ttm` 显著高于十年期国债收益率、低 PE/PB、分红连续
- **周期股**：盈利随行业周期波动，用 PE 反向逻辑 + PB 历史分位数
- **质量白马股**：ROE 高且稳定、现金流质量好
- **困境反转**：盈利刚扭亏，用 PB/PS + 资产负债表健康度

新增类型时：在 `references/` 新增对应子 md（复制成长股.md 结构），并在本文件
与 SKILL.md 中登记即可，脚本无需改动（衍生指标已覆盖通用字段）。

# 成长股评估框架（打分卡）

> 方法来源：Peter Lynch 的 GARP/PEG 体系、Graham 的安全边际思想、
> 质量因子（ROE/毛利率/现金流）等业界共识，均为可复现的经典方法。
> 所有分数必须引用 `derived_metrics.json` 的真实数值，禁止拍脑袋。

## 权重设计（按重要性排序，合计 100）

| 排序 | 维度 | 权重 | 设计理由 |
|------|------|------|---------|
| 1 | 成长性（含稳定性） | 35 | 成长股的第一性：成长是回报的源头，稳定性决定成长能否兑现，两项合计过半 |
| 2 | 盈利质量 | 25 | 区分真成长与纸面成长（现金流/毛利率/净利率/ROE）；**盈利不行，估值分位没有意义** |
| 3 | 估值吸引力 | 20 | 安全边际过滤器（PEG + 分位），只防"买贵"，不是给分主力 |
| 4 | 财务健康 | 12 | 排雷项是否决项，但正常公司天然高分、区分度低 |
| 5 | 流动性与规模 | 8 | 实用过滤（好买好卖），与基本面质量无关，权重最低 |

> **基本面 60 vs 估值 20**：成长股赚的是"成长兑现"的钱，不是"估值修复"的钱。
> 基本面（成长+质量）合计 60 分，估值仅 20 分——低估值无法掩盖平庸基本面。

## 打分卡（总分 100）

### 1. 成长性（35 分）

| 指标 | 满分 | 判定 | 数据来源 |
|------|------|------|---------|
| 近 3 年营收增速均值 | 12 | ≥20% → 12；10–20% → 8；0–10% → 5；<0 → 0 | `rev_yoy_avg3` |
| 近 3 年净利增速均值 | 12 | ≥25% → 12；10–25% → 8；0–10% → 5；<0 或不可得 → 0。**小基数打折**：最新年度归母净利 < 30 亿 → ×0.8 | `profit_yoy_avg3`、`income.json n_income_attr_p` |
| 增速持续性（近 3 年营收正增长年数） | 3 | 3 年 → 3；2 年 → 2；1 年 → 1；0 年 → 0 | `rev_positive_years` |
| 增速稳定性（近 3 年净利增速变异系数） | 3 | CV < 0.6 → 3；0.6–1.0 → 1；>1.0 → 0；样本 < 3 年 → 0 并标注 | `fina_indicator` 年度 `netprofit_yoy` 序列 |
| 扣非质量（近 3 年扣非增速均值） | 5 | ≥10% → 5；0–10% → 3；<0 或不可得 → 0 | `deducted_yoy_avg3` |

### 2. 盈利质量（25 分）

| 指标 | 满分 | 判定 | 数据来源 |
|------|------|------|---------|
| 毛利率（最新报告期） | 5 | ≥40% → 5；25–40% → 3；10–25% → 1；<10% → 0 | `gross_margin` |
| 净利率（最新报告期） | 5 | ≥10% → 5；5–10% → 3；2–5% → 1；<2% → 0 | `net_margin` |
| 经营现金流/归母净利润 | 10 | ≥1 → 10；0.5–1 → 6；0–0.5 → 3；<0 或不可得 → 0 | `ocf_to_np` |
| ROE（加权，最新年度） | 5 | ≥15% → 5；8–15% → 3；<8% → 0 | `roe_waa` |

### 3. 估值吸引力（20 分）

| 指标 | 满分 | 判定 | 数据来源 |
|------|------|------|---------|
| PEG（**混合 PEG**：PE-TTM ÷ 一致预期增速） | 12 | <1 → 12；1–1.5 → 8；1.5–2 → 4；>2 → 0；不适用 → 0 并标注。**预告口径打折**：`growth_basis=forecast` 时 ×0.7 | `peg`（分母口径见 `growth_basis`/`growth_period`） |
| 近 5 年 PE-TTM 分位数 | 8 | <25% → 8；25–50% → 6；50–75% → 3；>75% → 0；不可得 → 0 并标注。**质量联动**：最新年度 ROE < 8% 或 最新报告期净利率 < 5% 时，上限减半（满分 8 → 4）——盈利不行，低分位不是安全边际而是基本面恶化的镜像 | `pe_ttm_percentile_5y`、`roe_waa`、`net_margin` |

### 4. 财务健康（12 分）

| 指标 | 满分 | 判定 | 数据来源 |
|------|------|------|---------|
| 资产负债率 | 7 | <40% → 7；40–60% → 5；60–80% → 3；>80% → 0 | `debt_to_assets` |
| 排雷项（扣分制，每项扣 2.5，最多扣 5） | 5 | ①经营现金流连续 2 年为负；②应收/存货增速显著高于营收增速（脚本未覆盖时以现金流质量近似）；③商誉等大额减值风险（无数据则跳过，不扣分） | `ocf_to_np` 等 |

### 5. 流动性与规模（8 分）

| 指标 | 满分 | 判定 | 数据来源 |
|------|------|------|---------|
| 日均成交额 | 5 | ≥1 亿 → 5；0.3–1 亿 → 3；<0.3 亿或不可得 → 0 | `avg_daily_amount_yi` |
| 总市值 | 3 | ≥100 亿 → 3；30–100 亿 → 2；<30 亿 → 0 | `total_mv_yi` |

## 综合评级

| 总分 | 评级 | 解读 |
|------|------|------|
| ≥ 75 | 🟢 低估/优质 | 成长与质量俱佳且估值不贵，可关注 |
| 60–74 | 🟡 合理 | 基本面正常，估值合理，中性 |
| 45–59 | 🟠 谨慎 | 估值偏高或质量存疑，需进一步研究 |
| < 45 | 🔴 回避 | 高估或基本面明显偏弱 |

**质量底线封顶**：最新报告期净利率 < 2%，或最新年度 ROE < 5% 时，
即使总分 ≥ 75，评级也**封顶为 🟠 谨慎**（几乎不赚钱的公司不配"低估/优质"），
并在 flags 中标注触发原因。

## 数据缺失处理

- 单个指标缺失（脚本标 "数据不可得"）：该指标按 0 分处理，并在输出中
  明确标注"该维度数据不可得，按 0 分计"，**不得用其他数据猜测替代**。
- `peg` 不适用（增速 ≤ 0 或 PE 非正）：按 0 分并标注原因，不硬算。
  PEG 分母的优先级回退（一致预期 → 业绩预告 → TTM → 累计同比 → 3 年均值）
  在输出中通过 `growth_basis` 显式标注，打分时不得跳过标注。
- 一致预期与 TTM 实际增速差距过大（如 > 15 个百分点）时，PEG 得分
  下调一档（如 15 → 10），并在风险提示中说明"市场预期显著高于实际增速"。
- 分位数不可得（样本 < 60 个交易日，常见于次新股）：按 0 分并标注，
  且综合评级自动降一档（数据不足以支撑"低估"结论）。

## 输出要求

1. 每一维分数旁必须列出依据数值（如 "成长性 22/30，营收增速均值 24%，净利增速均值 31%"）。
2. 打分完成后附关键数据表（真实值 + 来源字段名）。
3. 风险提示：单维极端情况（如 PEG 高但增速极快、毛利率下滑趋势）须单独说明。
4. 免责声明：本内容仅为数据分析，不构成投资建议。

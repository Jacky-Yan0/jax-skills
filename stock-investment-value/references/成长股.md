# 成长股评估框架（打分卡）

> 方法来源：Peter Lynch 的 GARP/PEG 体系、Graham 的安全边际思想、
> 质量因子（ROE/毛利率/现金流）等业界共识，均为可复现的经典方法。
> 所有分数必须引用 `derived_metrics.json` 的真实数值，禁止拍脑袋。

## 打分卡（总分 100）

### 1. 成长性（30 分）

| 指标 | 满分 | 判定 | 数据来源 |
|------|------|------|---------|
| 近 3 年营收增速均值 | 10 | ≥20% → 10；10–20% → 7；0–10% → 4；<0 → 0 | `rev_yoy_avg3` |
| 近 3 年净利增速均值 | 10 | ≥25% → 10；10–25% → 7；0–10% → 4；<0 或不可得 → 0 | `profit_yoy_avg3` |
| 增速持续性（近 3 年营收正增长年数） | 5 | 3 年 → 5；2 年 → 3；1 年 → 1；0 年 → 0 | `rev_positive_years` |
| 扣非质量（近 3 年扣非增速均值） | 5 | ≥10% → 5；0–10% → 3；<0 或不可得 → 0 | `deducted_yoy_avg3` |

### 2. 盈利质量（20 分）

| 指标 | 满分 | 判定 | 数据来源 |
|------|------|------|---------|
| 毛利率（最新报告期） | 5 | ≥40% → 5；25–40% → 3；10–25% → 1；<10% → 0 | `gross_margin` |
| 经营现金流/归母净利润 | 10 | ≥1 → 10；0.5–1 → 6；0–0.5 → 3；<0 或不可得 → 0 | `ocf_to_np` |
| ROE（加权，最新年度） | 5 | ≥15% → 5；8–15% → 3；<8% → 0 | `roe_waa` |

### 3. 估值吸引力（30 分）

| 指标 | 满分 | 判定 | 数据来源 |
|------|------|------|---------|
| PEG（**混合 PEG**：PE-TTM ÷ 一致预期增速） | 15 | <1 → 15；1–1.5 → 10；1.5–2 → 5；>2 → 0；不适用 → 0 并标注 | `peg`（分母口径见 `growth_basis`/`growth_period`） |
| 近 5 年 PE-TTM 分位数 | 15 | <25% → 15；25–50% → 10；50–75% → 5；>75% → 0；不可得 → 0 并标注 | `pe_ttm_percentile_5y` |

### 4. 财务健康（15 分）

| 指标 | 满分 | 判定 | 数据来源 |
|------|------|------|---------|
| 资产负债率 | 10 | <40% → 10；40–60% → 6；60–80% → 3；>80% → 0 | `debt_to_assets` |
| 排雷项（扣分制，每项扣 2.5，最多扣 5） | 5 | ①经营现金流连续 2 年为负；②应收/存货增速显著高于营收增速（脚本未覆盖时以现金流质量近似）；③商誉等大额减值风险（无数据则跳过，不扣分） | `ocf_to_np` 等 |

### 5. 流动性与规模（5 分）

| 指标 | 满分 | 判定 | 数据来源 |
|------|------|------|---------|
| 日均成交额 | 3 | ≥1 亿 → 3；0.3–1 亿 → 2；<0.3 亿或不可得 → 0 | `avg_daily_amount_yi` |
| 总市值 | 2 | ≥100 亿 → 2；30–100 亿 → 1；<30 亿 → 0 | `total_mv_yi` |

## 综合评级

| 总分 | 评级 | 解读 |
|------|------|------|
| ≥ 75 | 🟢 低估/优质 | 成长与质量俱佳且估值不贵，可关注 |
| 60–74 | 🟡 合理 | 基本面正常，估值合理，中性 |
| 45–59 | 🟠 谨慎 | 估值偏高或质量存疑，需进一步研究 |
| < 45 | 🔴 回避 | 高估或基本面明显偏弱 |

## 数据缺失处理

- 单个指标缺失（脚本标 "数据不可得"）：该指标按 0 分处理，并在输出中
  明确标注"该维度数据不可得，按 0 分计"，**不得用其他数据猜测替代**。
- `peg` 不适用（增速 ≤ 0 或 PE 非正）：按 0 分并标注原因，不硬算。
  PEG 分母的优先级回退（一致预期 → 业绩预告 → TTM → 累计同比 → 3 年均值）
  在输出中通过 `growth_basis` 显式标注，打分时不得跳过标注。
- 一致预期与 TTM 实际增速差距过大（如 > 15 个百分点）时，PEG 得分
  下调一档（如 15 → 10），并在风险提示中说明"市场预期显著高于实际增速"。
- 分位数不可得（样本 < 60 个交易日，常见于次新股）：按 0 分并标注，
  且综合评级自动降一档（数据不足以支撑"低估"结论）。

## 输出要求

1. 每一维分数旁必须列出依据数值（如 "成长性 22/30，营收增速均值 24%，净利增速均值 31%"）。
2. 打分完成后附关键数据表（真实值 + 来源字段名）。
3. 风险提示：单维极端情况（如 PEG 高但增速极快、毛利率下滑趋势）须单独说明。
4. 免责声明：本内容仅为数据分析，不构成投资建议。

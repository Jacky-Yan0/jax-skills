# 通用指标与公式

本文件定义评估中用到的指标定义、公式与口径，全部对应
`scripts/fetch_fundamentals.py` 输出字段，**口径以 tushare 官方文档为准**。

## 估值指标（来源：`daily_basic`，见 valuation.json）

| 字段 | 定义 | 说明 |
|------|------|------|
| `pe` | 市盈率（静态） | 总市值 / 上年净利 |
| `pe_ttm` | 市盈率（TTM） | 总市值 / 最近 4 季净利，**成长股评估默认用 PE-TTM** |
| `pb` | 市净率 | 总市值 / 净资产 |
| `ps_ttm` | 市销率（TTM） | 总市值 / 最近 4 季营收 |
| `dv_ttm` | 股息率（TTM） | 近 12 个月分红 / 市值，% |
| `total_mv` | 总市值（万元） | 换算亿元：`/10000` |

## 成长性指标（来源：`fina_indicator` 年度）

- `or_yoy`：营收同比增长率（%），近 3 年取均值 → `rev_yoy_avg3`
- `netprofit_yoy`：净利润同比增长率（%），近 3 年取均值 → `profit_yoy_avg3`
- `dt_netprofit_yoy`：**扣非**净利润同比增长率（%）→ `deducted_yoy_avg3`
  （扣非 = 剔除一次性损益，防止卖资产/补贴制造的"假成长"）

## 关键公式

### PEG（Peter Lynch / GARP 体系）—— 采用**混合 PEG**

```
混合 PEG = PE-TTM ÷ 一致预期增速(%)
```

- **分子**：`pe_ttm`（总市值 ÷ TTM 净利，来自 `daily_basic`，真实数据）。
- **分母**：**一致预期增速**（券商研报聚合的未来盈利增速，来自 `report_rc`）。
  这是业界最主流的"混合 PEG"口径：分子用现实（TTM），分母用前瞻（一致预期），
  兼顾可验证性与前瞻性（Lynch 原意）。

#### 增速分母的获取优先级（逐级回退，显式标注来源）

| 优先级 | 口径 | 数据来源 | 说明 |
|-------|------|---------|------|
| 1 | **一致预期增速** | `report_rc`（券商研报聚合） | 前瞻、最贴近 PEG 本意；仅当有研报覆盖时可用 |
| 2 | 业绩预告中值 | `forecast`（`p_change_min/max` 均值） | 公司自己的前瞻；仅当预告报告期不早于最新财报报告期时采用 |
| 3 | TTM 净利同比 | `income` 单季数据滚动 12 个月 | 现实锚：季节性对齐、比累计同比新鲜；一次性损益滚出窗口会跳变 |
| 4 | 最新报告期累计同比 | `fina_indicator.netprofit_yoy` | 标注报告期（如 2026Q1（1-3月累计）），季节性强弱可见 |
| 5 | 近 3 年净利增速均值 | `fina_indicator` 年度数据 | 兜底，最保守 |

- 输出时**必须**标注所用口径与覆盖期（`growth_basis` / `growth_period`）。
- 一致预期增速与 TTM 实际增速**同时输出**（`consensus_growth` / `ttm_profit_yoy`），
  用于对比"市场预期 vs 公司现实"：差距过大时 PEG 可信度需打折扣
  （分析师存在系统性乐观偏差，实证平均高估 10–20%）。
- 判定：PEG < 1 低估；1–1.5 合理；1.5–2 偏高；> 2 高估。
- **限制**：增速 ≤ 0 或 PE 非正时 PEG 无意义，不计算、不硬凑。

### 历史估值分位数（均值回归思想）

```
分位数 = 历史序列中 ≤ 当前值的个数 ÷ 有效样本数 × 100
```

- 取近 5 年每日 `pe_ttm`/`pb`，**只统计正值**（亏损期 PE 为负，剔除）。
- 样本 < 60 个交易日（次新股）→ 标记"数据不可得"。
- 判定：<25% 历史低位；25–50% 中低位；50–75% 中高位；>75% 历史高位。

### 现金流质量

```
经营现金流/归母净利润 = n_cashflow_act ÷ n_income_attr_p（最近年度）
```

- ≥ 1 为健康（利润有真金白银支撑）；明显 < 1 需警惕"纸面利润"。
- 来源：`cashflow.json` 与 `income.json`，见 `ocf_to_np`。

### 年化波动率（流动性参考）

```
年化波动率 = 近1年日收益率标准差 × √252
```

- 来源：`daily.json`，见 `volatility_annual`。

## 判断口径提醒（常见陷阱）

1. **周期股不能用低 PE 判低估**：周期股盈利高点 PE 低（是卖出区）、
   盈利低点 PE 高（是观察区）——本框架已排除周期股，勿误用。
2. **一次性收益陷阱**：净利高增但扣非增速为负 → 假成长，成长性扣分。
3. **PEG 增速口径**：默认用一致预期增速（混合 PEG）；无研报覆盖时按
   优先级链回退，**每个口径都显式标注来源与覆盖期**，禁止混用不标注。
4. **新股/次新股**：历史分位数不可得，按缺失处理并降档，不硬评"低估"；
   同理无研报覆盖时一致预期不可得，回退 TTM/累计同比口径。

## 数据边界声明

- 所有数字来自 tushare 公开接口，以披露为准，财报有滞后性（输出注明数据截止日）。
- 一致预期（`report_rc`）为券商预测聚合，含乐观偏差，仅作参考；
  无覆盖/权限不足时按"数据不可得"处理，回退下一级口径，绝不编造。
